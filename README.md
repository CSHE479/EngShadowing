# 開口跟讀

給英聽與口說初學者的繁體中文跟讀 App。雙擊 `start.bat`，會用預設瀏覽器開啟 http://localhost:8765/（建議 Edge 或 Chrome，瀏覽器會記住麥克風授權）。學習紀錄綁定這個網址。

## 安裝到手機（PWA）

麥克風只能在 HTTPS 下使用，所以要先放上網站：

1. 在 GitHub 建立 repository，把這個資料夾的檔案上傳到根目錄（`start.bat`、`serve.ps1` 不需要）。
2. 到 Settings → Pages，Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等一兩分鐘，打開 `https://帳號.github.io/專案名/`。
4. Android：用 Chrome 開啟，選單 →「安裝應用程式」或「加到主畫面」。iPhone：用 Safari 開啟，分享 →「加入主畫面」。

之後更新程式只要重新上傳，手機連網開啟時會取得新版。學習紀錄電腦與手機各自獨立，要轉移請用「句庫」頁的匯出備份與還原。

## 設計決定

| 問題 | 決定 | 原因 |
|---|---|---|
| 形式 | 純前端網頁 | 免安裝，不碰其他專案 |
| 語音 | 瀏覽器內建語音（優先選 Natural 語音） | 免費，能調速度 |
| 口說檢查 | 語音辨識逐字比對 + 錄音比對原音 | 辨識只代表系統聽得懂，錄音才能聽出語調差異 |
| 音標 | 內建字典，缺的字連線查 dictionaryapi.dev 並快取 | 匯入的句子也有音標 |
| 句長 | 內建句多在 8 字以內 | 使用者無法用英文思考，不可過度複雜 |
| 複習 | 1、3、7、14 天間隔 | 自評即可，不增加負擔 |
| 資料 | 只存本機瀏覽器，可匯出備份 | 不需帳號 |

## 引導方法

每句固定五步：看懂 → 慢慢聽 → 分段跟 → 影子跟讀 → 評分。每步只給一個主要按鈕和一句中文提示。AI 提示詞在 App 的「方法」頁。

## 聽寫

每天 3 題，由 `dictation.js` 的第 1 級依序往後出，只有實際開始做才會前進，不會因為幾天沒練就跳級。批改忽略大小寫和標點，`I'm` / `I am` 視為相同。答錯的字先留空讓使用者再聽一次，第二次才公布答案；第一次沒全對的句子自動加入再複習。

## 中翻英抽問

句庫連續播放結束後，從有中文翻譯的句子隨機抽 5 句，用中文出題，等使用者用說的或打字回答英文，不限時間。批改規則同聽寫，第一次沒全對的句子自動加入再複習。

## 限制

- 單音無法用瀏覽器語音單獨發出，發音表以例字代替。
- 語音辨識會把聲音傳給瀏覽器廠商的雲端服務，需要網路。
- 題庫為 10 組每日題、每主題 15 句，依日期循環；聽寫 30 句，循環前可練 10 天。在 `data.js`、`dictation.js` 新增項目即可擴充。
